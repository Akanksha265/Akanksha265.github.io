# 🌐 Personal Portfolio Website

A responsive and modern personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. This project showcases my skills, projects, achievements, and contact information in an interactive and user-friendly format.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Clean and modern user interface
- Interactive navigation
- Project showcase section
- About Me section
- Skills display
- Contact section
- Smooth scrolling and animations
- Optimized image assets

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Web Design
- Font Awesome 
- Google Fonts 

## 🎯 Usage

- Explore the portfolio sections.
- View showcased projects and skills.
- Use the contact section to connect with me.

## 📷 Assets

The repository contains:

- HTML source files
- CSS styling files
- JavaScript functionality files
- Portfolio images and screenshots
- Project assets and media resources
